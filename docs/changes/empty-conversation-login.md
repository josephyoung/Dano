# 空会话登录引导

用户确认采用 A 方案：菜单下方的横向提示条，右侧使用项目默认按钮样式的登录链接。
原型保存在 `codex-login-banner-prototype` 分支，提交 `41f6f674`；它只模拟状态，不进入产品代码。

- 默认“给{productName}发消息”标题为 1.6rem。
- 横幅仅在菜单的可信登录状态为 anonymous、当前会话没有消息且消息加载完成时出现。
- 开始聊天或登录后横幅隐藏；检查中和登录失效状态不重复提示，失效状态沿用重新登录弹窗。
- 登录入口复用菜单的当前页签跳转与 returnTo；横幅不新增关闭操作。
- 模型逐请求接收发起连接的可信状态，和菜单使用相同后台来源。状态不存入历史，不泄露凭据或登录会话 ID。
- 已登录时，业务脚本的凭据缺失按业务连接异常处理；状态未知时不能猜测用户未登录。

验证边界由用户确认：App 渲染、Assistant Turn/模型请求上下文、生产 Codex in-app Browser。
生产验收覆盖横幅出现/消失、标题字号、菜单一致性、当前页签登录返回，以及文本、bash ls、图片读取基线。

已复核并同步 `docs/skill-generator-ask-user-question-guide.md` 中的登录提示说明。
本次未改变 ask_user_question 的参数、Schema、控件、返回值或确认生命周期。
