# 管理员 Skill 热更新

统一容器入口持续协调 `DANO_SKILLS_DIR`（未设置时为 Agent Config Directory 的
`skills`）与 Runtime Data Directory 的 `.agents/skills`。不开放这些目录的相邻
配置或凭据。容器、HTTP 进程及聊天无需重启；会话历史和业务文件不做删除或重写。

## 发布与撤销边界

- 每 1 秒完整校验、读取并比较源树；每次 supervisor RPC 也先协调。这是内容轮询，
  不依赖文件 watcher，因此不受递归 watcher、丢事件或目录原子替换影响。
- 比较内容、名称、执行权限、所有者及文件身份；变化时二次读取校验。把已校验的
  字节写入新的、唯一的 `.operator-skills-XXXXXX` 只读发布目录。目录改名、删除、
  同路径重新安装和多来源批量修改均产生新版本；旧绝对路径不复用于新版本。
- 发现变化后先清空会话发现缓存，阻断新 worker 获取，关闭全部已运行和启动中的
  worker。Heimdall 的中止信号会杀死 shell 进程组；Bubblewrap 使用独立 PID
  namespace 与 `--die-with-parent`，broker 强制退出时旧 namespace 也被销毁。
  已退出 worker 的旧只读挂载不能被继续使用。
- **更新生效点**为旧 worker 撤销完成、旧发布目录删除、新目录和版本发布完成。
  所有读取/执行经过 root supervisor 的版本检查；旧上下文中的路径不是执行授权。
  资源失效通知也会通过 Pi 公开 abort 接口中止旧 Assistant Turn；所有模型工具（包括宿主工具）在 tool_call 边界检查版本。
  已开始的调用收到取消信号，尚未执行的旧版本调用返回 `OPERATOR_SKILLS_CHANGED`，
  不会被 Dano 自动重放。用户在同一聊天发送下一条消息即可使用当前版本。
  取消不回滚生效点前已经发生的外部副作用，也不删除会话历史；可取消的宿主操作收到同一 Turn 的 abort 信号。
- 正常响应的文件系统和事件循环下，发现变化前最多 1 秒；源树扫描上限 2 秒，
  候选发布上限 2 秒。现有运行中 worker 立即开始关闭，最多等待 broker 的
  `shutdownTimeoutMs`（默认 5 秒）。启动中的 worker 最多还需其
  `startupTimeoutMs`（默认 30 秒），随后关闭。因此默认执行撤销上限为 **40 秒**
  （1 + 2 + 2 + 30 + 5），通常空闲/已启动 worker 远低于该保守上限。
  磁盘删除/权限写入失败时保持关闭的资源屏障，不授予旧版本或新 worker 权限；
  新资源可用性等待文件系统恢复，不假称这类故障仍可在固定时间内成功发布。
- Pi 通过公开 `ResourceLoader.reload()` / `getSkills()` 加载元数据，Dano 组合其
  资源接口，并在 `input`（Skill 命令展开前）和 `before_agent_start` 刷新。后台
  IPC 发布通知也会立即清空旧发现结果。一个 Assistant Turn 固定使用启动时版本；
  修改期间的后续工具调用失败，下一个 Turn 重新取得当前版本。

每次工具调用只挂载一个不可变发布版本，`SKILL.md`、references、scripts 不会在
同一次调用中切换。管理员需要跨多个文件发布一个逻辑版本时，应在源目录外准备完整
Skill，再原子替换目录；逐个文件写入期间可观察到的中间完整树也是一个源版本，
系统不能推断管理员尚未完成的编辑事务。

## 安全、错误及清理

源树保持 root/HTTP host 所有者检查，拒绝组/其他用户可写内容、符号链接、硬链接、
特殊文件和路径逃逸。Linux 通过已打开目录的 `/proc/self/fd` 锚定递归读取，检查
读取前后身份及元数据。Pi 无法解析/加载的 Skill 文档也视为无效；Pi 可加载的建议性
名称警告不扩大为安全失败。新树不安全、扫描超时或候选发布失败时返回
`UNSAFE_OPERATOR_SKILL`，撤销整个管理员资源发布，**不回退旧版本**。修复源目录后
下一次协调恢复资源。保守地撤销整个发布，可避免来源冲突时继续使用其他来源的旧副本。

只读资源不提供写权限，也不包含邻接 `.pi`/`.agents` 配置。用户与凭据隔离、非 root
HTTP、worker 身份和 Heimdall 保护保持不变。

每次更新删除上一发布目录；失败的候选也删除。启动时取得 supervisor 独占锁之后，
只清理安装目录内保留命名空间 `.operator-skills-` 加 6 位字母数字的旧生成目录，
校验所有者和目录类型，不清理其他管理员文件。运行时持久目录、用户文件、会话历史
和审计记录不属于清理范围。持久历史中的旧内容不删除，但不再授权执行旧版本。

## 验证

定向测试覆盖现有 Pi 会话发现刷新、双用户 IPC、运行中调用取消、旧版本请求拒绝、
新增/修改/删除/重命名、原子替换、重装、并发协调、轮询恢复、非法链接/权限/文档及
失效副本清理。真实内核隔离与模型验收须在现有服务器容器和原网址另行完成，不能用
这些测试替代。
